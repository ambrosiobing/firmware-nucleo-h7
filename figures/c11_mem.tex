\node[umlnote, text width=44mm, anchor=north west] at (92mm,32mm)
  {The receive ring is the one block the transfer engine writes, so it goes
   where that engine can reach. Which engine reaches which memory on this part
   is an open item and chapter 19 settles it.};
\node[umlnote, text width=42mm, anchor=north west] at (0mm,-4mm)
  {The ring is sized for the longest burst between two visits to the engine and
   not for the longest reply. Confusing the two is how a generous-looking ring
   overflows.};
\node[umlnote, text width=42mm, anchor=north west] at (46mm,-4mm)
  {Nothing is allocated at run time. An engine whose failure mode is heap
   exhaustion has replaced one unbounded behaviour with another.};
\node[umlnote, text width=38mm, anchor=north west] at (94mm,-4mm)
  {Porting to another module touches the command file and the unsolicited
   table. The engine itself does not change.};
